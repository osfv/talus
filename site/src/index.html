From noise to terrain in 25 steps

    Every map starts as random noise. At each step Talus predicts the clean terrain under the noise, and the sampler keeps a little more of that prediction. Above is the island from the generator at six of its 25 steps.

    We trained the 23M-parameter network from scratch on 45,000 maps from our own procedural generator: layered noise, rivers cutting valleys, and loose rock sliding down to its resting angle. That pile of rock at the foot of a slope is called talus.

    Here, ONNX Runtime runs the network on WebGPU, or on the CPU when WebGPU is missing. The same seed and settings give the same map.

    Take it into your engine

    Every map comes with a JSON file that gives its size and height range. For hundreds of maps, run Talus locally with the Python tool.

    git clone https://github.com/osfv/talus
cd talus && pip install -e .
gh release download v3.0.0 -R osfv/talus -p talus-3.pt -D checkpoints
nullscape sample --checkpoint talus-3 --archetype ridges \
    --n 64 --formats png16,r16,obj --unity
    Unity
    Terrain, Import Raw: 65 x 65, 16-bit, Windows byte order. Set the terrain to 4,032 m wide and 1,200 m high.
    Unreal and Godot
    Use the 16-bit PNG as a landscape or terrain heightmap and scale its height to 1,200 m.
    Blender
    Import the OBJ. It is in meters with Y up.
